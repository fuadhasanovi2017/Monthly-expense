# Personal Hisab — Android APK project

Android Studio project source for Personal Hisab.

## Build with Android Studio:
1. Open this folder in Android Studio.
2. Build > Build Bundle(s) / APK(s) > Build APK(s).
3. APK is generated at app/build/outputs/apk/debug/app-debug.apk

## Build with GitHub Actions:
1. Push to GitHub.
2. Actions > Build Personal Hisab APK > Run workflow.
3. Download personal-hisab-apk artifact.
